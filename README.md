## List of event this mod adds so far:
- Random Footsteps
- Doors opening/closing
- Trapdoors opening/closing
- Knocking on doors
- Custom whispers
- Torches may change into Soul Torches and back
- Creepy cloud of particles on the ground
- Eerie cave sounds
- Ladder sounds
- Minecart sounds
- False Block Breaking
- Page Turning sounds
- Button Press sounds

Most of these events actually need a specific block in the player's range, like buttons, rails, doors, torches, or bookshelves.
